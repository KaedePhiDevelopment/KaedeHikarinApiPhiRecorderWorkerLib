# Phi Recorder Native

本仓库是基于 [Phi Recorder](https://github.com/AntiLeave/Phi-Recorder) 的原生渲染库，提供 **无窗口的 EGL desktop OpenGL pbuffer 渲染**，可在 Linux/Windows 上运行。
